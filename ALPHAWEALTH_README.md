## 🤖 Гибридная архитектура

### 4 Экспертных комитета:

1. **💰 Wealth Detectives** (LightGBM)
   - Специализация: финансовые обороты
   - Фокус: анализ денежных потоков

2. **🎯 Behavior Decoders** (CatBoost)
   - Специализация: транзакционные паттерны
   - Фокус: поведение клиента

3. **📊 Credit Oracles** (XGBoost)
   - Специализация: данные БКИ
   - Фокус: кредитная история

4. **🎪 Lifestyle Analysts** (Random Forest)
   - Специализация: демография и цифровой след
   - Фокус: образ жизни

**Fusion Strategy:** Взвешенное голосование с динамическими весами на основе точности каждого эксперта.

## 🚀 Использование

### Обучение модели:

```bash
python train_model.py --data data/train.csv --model-type alpha_wealth --output models/income_model.pkl
```

### Предсказание с полным анализом:

```python
from src.alpha_predictor import AlphaWealthPredictor

predictor = AlphaWealthPredictor("models/income_model.pkl")
analysis = predictor.predict_full_analysis(client_data)

print(f"Доход: {analysis['predicted_income']}")
print(f"История: {analysis['financial_story']}")
print(f"Архетип: {analysis['financial_archetype']['name']}")
```

### Через API:

