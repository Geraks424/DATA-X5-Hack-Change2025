# ✅ Интеграция API завершена

API обновлен для соответствия формату из изображений.

## 🎯 Что было реализовано:

### 1. ✅ GET /api/clients

**Эндпоинт:** `GET /api/clients`

**Функциональность:**
- Загружает клиентов из `hackathon_income_test.csv`
- Возвращает список клиентов в формате:
  ```json
  [
    {
      "id": "0",
      "age": 34,
      "gender": "Мужской",
      "city": "Ижевск"
    }
  ]
  ```
- Автоматически определяет формат данных (id/Id, gender в разных форматах)
- Поддерживает опциональные поля (city, adminarea и др.)

**Файлы:** `src/api.py` (строки 142-216)

---

### 2. ✅ POST /api/predict

**Эндпоинт:** `POST /api/predict`

**Функциональность:**
- Принимает `{"client_id": "0"}` вместо полных данных
- Автоматически находит клиента в test данных
- Возвращает формат согласно изображению:
  ```json
  {
    "predicted_income": 85200,
    "shap_values": {
      "per_capita_income_rur_amt": 21000,
      "dda_rur_amt_cm_avg": 15000,
      ...
    },
    "recommendations": [
      {
        "product": "Автокредит до 1.5 млн",
        "reason": "Стабильный доход и низкая долговая нагрузка"
      }
    ]
  }
  ```

**Особенности:**
- SHAP values возвращаются как объект (dict) с названиями признаков
- Recommendations имеют поля `product` и `reason`
- Автоматическая генерация причин рекомендаций

**Файлы:** `src/api.py` (строки 219-308)

## 🚀 Использование:

### 1. Подготовка данных

Поместите файл `hackathon_income_test.csv` в папку `data/`:

```
data/
  └── hackathon_income_test.csv
```

### 2. Запуск API

```bash
python run_api.py
```

Или:

```bash
python -m uvicorn src.api:app --reload
```

### 3. Тестирование

**Получить список клиентов:**
```bash
curl http://localhost:8000/api/clients
```

**Получить прогноз:**
```bash
curl -X POST http://localhost:8000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"client_id": "0"}'
```

## 📋 Формат данных

### hackathon_income_test.csv должен содержать:

**Обязательные поля:**
- `id` или `Id` - идентификатор клиента
- `age` - возраст
- `gender` / `Gender` / `пол` / `Пол` - пол

**Опциональные поля:**
- `city` / `City` / `город` / `Город` - город
- `adminarea` / `AdminArea` - регион
- Остальные признаки для ML модели
