# ⚡ Быстрая установка за 3 шага

## Для Windows:

1. **Откройте командную строку** в папке проекта
2. **Запустите:**
   ```
   install.bat
   ```
3. **Готово!** Все зависимости установлены ✅

## Для Linux/Mac:

1. **Откройте терминал** в папке проекта
2. **Запустите:**
   ```bash
   chmod +x install.sh
   ./install.sh
   ```
3. **Готово!** Все зависимости установлены ✅

## Проверка:

```bash
python check_installation.py
```

## Что дальше?

1. Поместите данные в `data/` (train.csv, test.csv)
2. Обучите модель: `python train_model.py`
3. Запустите: `python run_app.py`
