# 📁 Структура проекта

## Обзор компонентов

### 🧠 Machine Learning компоненты

| Файл | Описание |
|------|----------|
| `src/data_processing.py` | Обработка данных, feature engineering, предобработка |
| `src/model_trainer.py` | Обучение моделей (XGBoost, LightGBM, CatBoost) |
| `src/predictor.py` | Загрузка модели и генерация предсказаний |
| `train_model.py` | Скрипт для обучения модели из командной строки |

**Функциональность:**
- Обработка пропущенных значений
- Feature engineering (возрастные группы, логарифмические трансформации)
- Кодирование категориальных признаков
- Обучение моделей с оптимизацией WMAE
- Сохранение/загрузка моделей

### 🔌 Backend API

| Файл | Описание |
|------|----------|
| `src/api.py` | FastAPI приложение с REST endpoints |
| `run_api.py` | Скрипт запуска API сервера |

**Endpoints:**
- `POST /predict` - предсказание дохода для одного клиента
- `POST /batch_predict` - пакетное предсказание
- `POST /shap_explain` - SHAP объяснения предсказания
- `GET /recommend/{income}` - рекомендации продуктов
- `GET /feature_importance` - важность признаков
- `GET /health` - проверка работоспособности

### 🎨 Frontend интерфейс

| Файл | Описание |
|------|----------|
| `streamlit_app.py` | Streamlit веб-приложение |
| `run_app.py` | Скрипт запуска полного приложения |

**Разделы:**
1. **Предсказание дохода** - форма ввода данных клиента
2. **Клиентская база** - пакетная обработка
3. **Аналитика модели** - важность признаков
4. **Мониторинг** - метрики качества

### 💼 Бизнес-логика

| Файл | Описание |

**Функциональность:**
- Автоматический подбор продуктов по доходу

## Поток данных

```
1. Данные (CSV)
   ↓
2. Обработка данных (data_processing.py)
   ↓
3. Обучение модели (model_trainer.py)
   ↓
4. Сохранение модели (models/income_model.pkl)
   ↓
5. Загрузка модели (predictor.py)
   ↓
6. API запросы (api.py)
   ↓
7. Веб-интерфейс (streamlit_app.py)
   ↓
8. Визуализация и рекомендации
```

## Зависимости между модулями

```
streamlit_app.py
  └─→ src.api (HTTP requests)
       ├─→ src.predictor
       │    ├─→ src.model_trainer
       │    └─→ src.data_processing
       ├─→ src.product_recommender
       └─→ SHAP (объяснения)

train_model.py
  └─→ src.model_trainer
       └─→ src.data_processing

generate_submission.py
  └─→ src.predictor
       ├─→ src.model_trainer
       └─→ src.data_processing
```

## Технологический стек

### Data Science
- **pandas** - обработка данных
- **numpy** - численные вычисления
- **scikit-learn** - ML утилиты
- **xgboost/lightgbm/catboost** - градиентный бустинг
- **shap** - объяснимость модели

### Backend
- **FastAPI** - REST API фреймворк
- **uvicorn** - ASGI сервер
- **pydantic** - валидация данных

### Frontend
- **Streamlit** - веб-интерфейс
- **Plotly** - интерактивная визуализация

### Infrastructure
- **Docker** - контейнеризация
- **Python 3.9+** - язык программирования

## Расширяемость

### Добавление новых признаков
1. Обновите `src/data_processing.py` (метод `create_features`)
2. Переобучите модель
3. Обновите веб-интерфейс (если нужно)

### Добавление новых продуктов
1. Обновите `config.yaml` (секция `products`)
2. Изменения применятся автоматически

### Добавление новых моделей
1. Добавьте метод в `src/model_trainer.py`
2. Обновите `config.yaml`
3. Используйте `--model-type` при обучении
